# CMPG325-Mokone-Network-Project-31120997

## Project Overview
This repository contains the network design, packet tracer simulations, and configuration documentation for Mokone Legal Chambers (Client ID: CLI-079). The objective is to establish a secure, segmented network using single-area dynamic routing( OSPF ) and Access Control Lists (ACLs) on a central router to separate the Legal and Admin departments while allowing for the sharing  of printing resources from a shared printer zone (CR8).

## Repository Structure
* **/documentation:** Contains the written Network Plan reports, client requirement documentation and any other relevant documentation.
* **/diagrams:** physical and logical topology diagrams/packet tracer screenshots
* **/packet_tracer:** Cisco Packet Tracer (`.pkt`) simulation files at various stages of development.
* **/configs:** exported text backups of the `running-config` for the default gateway router and access-layer switches.
